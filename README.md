# Portfolio

ゲームクライアントプログラマー / AI活用推進リーダーのポートフォリオサイト。

GitHub Pages で公開: https://mooman0222.github.io/Portfolio/

## 構成

- `index.html` - メインページ（プロフィール・実績・スキル・AI活動・研究・お問い合わせ）
- `css/style.css` - スタイルシート
- `js/main.js` - ナビゲーション・スクロールアニメーション等

## ローカルでの確認

```bash
python3 -m http.server 8000
```

http://localhost:8000 で確認できます。

## 公開方法

GitHub の Settings → Pages で、Source を `Deploy from a branch` → `main` / root に設定してください。
